## 3주차: React 개념 파악하기 

## 08. Create

### 1. 핵심 개념
* 상태 승격 (State Lifting): 새로운 항목을 추가하려면 기존의 topics 배열을 상위 컴포넌트의 state로 끌어올려 관리해야 한다. 
* 불변성(Immutability) 유지: 리액트에서 배열이나 객체 같은 복합 데이터를 수정할 때는 원본을 직접 수정하지 않고, 복제본을 만들어 수정한 뒤 set 함수에 전달해야 변경을 감지하고 화면을 다시 렌더링한다.
* 배열 복제: [...기존배열] (Spread 연산자 사용)


### 2. 코드 예시
```javascript
function onCreate(title, body) {
  const newTopic = { id: nextId, title, body };
  setTopics([...topics, newTopic]);

  setMode('READ');
  setId(nextId);
  setNextId(prevId => prevId + 1);
}
```

## 09. Update

### 1. 핵심 개념
* 복합 기능(Update): Update는 기존 데이터를 불러오는 Read와, 수정된 데이터를 저장하는 Create 기능이 결합된 작업이다.
* Prop to State: props는 읽기 전용으로, 입력 폼에서 임시로 수정해야 할 경우에 한해 state로 복사하여 사용한다.
* 가변적인 UI: 수정 버튼은 상세보기(READ) 모드일 때만 나타나도록 맥락(Context)에 맞게 구성하는 것이 좋다.


### 2. 코드 예시
```javascript
import { useState, useEffect } from 'react';

function Update({ title: initialTitle, body: initialBody, onUpdate }) {
  const [title, setTitle] = useState(initialTitle);
  const [body, setBody] = useState(initialBody);

  // props가 바뀌면 state도 함께 갱신
  useEffect(() => {
    setTitle(initialTitle);
    setBody(initialBody);
  }, [initialTitle, initialBody]);

  return (
    <form onSubmit={(e) => {
      e.preventDefault();
      onUpdate(title, body);
    }}>
      <input
        type="text"
        value={title}
        onChange={(e) => setTitle(e.target.value)}
      />
      <textarea
        value={body}
        onChange={(e) => setBody(e.target.value)}
      />
      <input type="submit" value="Update" />
    </form>
  );
}
```

## 10. Delete

### 1. 핵심 개념
* 버튼 사용: 삭제는 페이지 이동이 아닌 즉시 실행되는 작업이므로, 링크(`<a>`)보다 `<button>`을 사용하는 것이 적절하다.
* 배열 필터링: 삭제하려는 ID와 일치하지 않는 항목들만 남겨 새로운 배열을 만들고, 이를 state로 업데이트한다.
* 정리정돈(Fragment): 여러 JSX 요소를 그룹핑할 때는 Fragment(`<> </>`)를 사용하여 불필요한 div 생성을 피할 수 있다.


### 2. 코드 예시
```javascript
<button onClick={() => {
  // 반복문을 사용한 삭제 로직 (불변성 유지)
  const newTopics = [];
  for (let i = 0; i < topics.length; i++) {
    if (topics[i].id !== id) {
      newTopics.push(topics[i]);
    }
  }
  setTopics(newTopics);

  // 권장 방식: filter를 사용한 더 간결한 삭제 로직
  // setTopics(topics.filter(topic => topic.id !== id));

  setMode('WELCOME');
}}>
  Delete
</button>
```
