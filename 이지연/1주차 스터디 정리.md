## 1주차: React 개념 파악하기 - 04 컴포넌트 만들기

### 1. 핵심 개념
* "리액트는 사용자 인터페이스를 구축하기 위한 선언적이고 효율적인 자바스크립트 라이브러리로, 사용자 정의 태그를 만드는 기술이다"
* 복잡한 HTML 코드를 연관된 것들끼리 그룹핑하여 이름을 붙인 독립적인 부품을 컴포넌트(Component)라고 부른다.

### 2. 컴포넌트를 사용하는 이유 (장점)
1. **가독성 및 정리정돈**: 수만 줄의 HTML 코드를 `Header`, `Nav`, `Article`과 같이 의미 있는 태그로 추상화하여 전체 구조를 쉽게 파악할 수 있다.
2. **재사용성**: 한 번 만들어둔 컴포넌트는 필요한 곳 어디서든 반복해서 사용할 수 있다.
3. **유지보수의 효율성**: 컴포넌트 내부의 코드 한 곳만 수정하면, 해당 컴포넌트를 사용 중인 모든 페이지에 변경 사항이 일괄 적용됨.
4. **생산성 및 공유**: 오픈 소스로 공개된 다른 사람의 컴포넌트를 가져다 쓰거나, 내가 만든 것을 공유함으로써 개발 속도를 높일 수 있음.

### 3. 컴포넌트 제작 규칙
* **함수로 정의**: JavaScript 함수를 사용하여 컴포넌트의 기능을 정의한다. 
* **대문자로 시작 (PascalCase)**: 리액트가 일반 HTML 태그와 구분할 수 있도록 반드시 첫 글자는 **대문자**로 작성해야 한다. 
  * `header` (X) : 표준 HTML 태그
  * `Header` (O) : 사용자 정의 컴포넌트
* **JSX 반환**: 함수의 `return` 값으로 화면에 그릴 HTML 형태의 코드(JSX)를 반환한다. 

### 4. 코드 예시
```javascript
import './App.css';

// 1. 컴포넌트 정의 (대문자로 시작)
function Header() {
  return <header>
    <h1><a href="/">WWW</a></h1>
  </header>
}

function Nav() {
  return <nav>
    <ol>
      <li><a href="/read/1">html</a></li>
      <li><a href="/read/2">css</a></li>
    </ol>
  </nav>
}

function App() {
  return (
    <div>
      {/* 2. 컴포넌트 사용 (사용자 정의 태그) */}
      <Header />
      <Nav />
      <article>
        <h2>Welcome</h2>
        Hello, React!
      </article>
    </div>
  );
}

export default App;
