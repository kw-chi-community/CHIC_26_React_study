## 05. Props

### 1. 핵심 개념
* 리액트는 속성을 props라고 부른다.
* 중괄호 { }의 역할: JSX 내부에서 중괄호 사이에 있는 정보는 일반적인 문자열이 아닌 표현식(Expression)으로 취급되어 해석되고 반영된다. 

### 2. 코드 예시
영상에서 강조된 topics 배열을 반복문으로 처리하여 li 태그들을 동적으로 생성하는 로직
```javascript
function Nav(props) {
  const lis = [];
  
  // props로 전달받은 topics 배열의 길이만큼 반복
  for (let i = 0; i < props.topics.length; i++) {
    let t = props.topics[i];
    
    // 배열에 JSX 요소를 push (이때 고유한 key 값이 필수)
    lis.push(
      <li key={t.id}>
        <a href={'/read/' + t.id}>{t.title}</a>
      </li>
    );
  }

  return (
    <nav>
      <ol>
        {lis} {/* 생성된 li 배열이 이곳에 표현식으로 해석되어 출력됨 */}
      </ol>
    </nav>
  );
}
```

## 06. event

### 1. 핵심 개념

* 컴포넌트에 이벤트 기능 부여: HTML 태그에 onclick이 있듯, 우리가 직접 만든 컴포넌트에도 커스텀 이벤트를 만들어 속성(props)으로 전달할 수 있다. 
* 문법적 차이: 리액트의 이벤트는 순수 HTML과 달리 onClick처럼 카멜 케이스(camelCase)를 사용하며, 따옴표 대신 중괄호 { }를 사용해 함수를 전달한다. 
* 기본 동작 방지 (event.preventDefault()): <a> 태그의 클릭 이벤트 발생 시 페이지가 새로고침되는 등의 브라우저 기본 동작을 막기 위해 사용한다.

## 07. state

### 1. 핵심 개념

* State란?: 컴포넌트 내부에서 변할 수 있는 값으로, 이 값이 바뀌면 리액트는 해당 컴포넌트 함수를 다시 실행하여 새로운 UI를 렌더링한다.  
* Props vs State: Props은 컴포넌트를 사용하는 '외부자'를 위한 데이터라면, State는 컴포넌트를 직접 만드는 '내부자'를 위한 데이터이다. 
* useState 훅: 리액트에서 상태를 관리할 때 사용하는 함수로, [상태값, 상태를바꾸는함수] 형태의 배열을 반환한다.

### 2. 코드 예시
`useState`를 사용하여 관리하고, 사용자의 클릭 이벤트에 따라 화면을 동적으로 바꾸는 로직
```javascript
import { useState } from 'react'; // 1. useState 임포트

function App() {
  // 2. 상태 생성: [읽기용 데이터, 변경용 함수] = useState(초기값)
  const [mode, setMode] = useState('WELCOME');
  let content = null;

  // 3. 상태에 따른 조건부 렌더링
  if (mode === 'WELCOME') {
    content = <article><h2>Welcome</h2>Hello, WEB</article>;
  } else if (mode === 'READ') {
    content = <article><h2>Read</h2>Hello, Read Mode</article>;
  }

  return (
    <div>
      {/* 4. 이벤트 발생 시 상태 변경 함수(setMode) 호출 */}
      <Header title="WEB" onChangeMode={() => {
        setMode('WELCOME'); // 클릭 시 mode가 WELCOME으로 바뀌며 컴포넌트 재실행
      }} />
      <Nav onChangeMode={() => {
        setMode('READ');    // 클릭 시 mode가 READ로 바뀌며 컴포넌트 재실행
      }} />
      {content}
    </div>
  );
}
```
