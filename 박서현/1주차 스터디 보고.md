# 1주차 - ch4 컴포넌트 만들기

## 핵심 개념

React = 사용자 정의 태그(컴포넌트)를 만드는 기술
복잡한 코드 여러 줄을 하나의 코드(컴포넌트 호출)로 줄이는 방식

## 컴포넌트(사용자 정의 태그) 만드는 법

함수를 정의해서 사용자 정의 태그(컴포넌트)를 만든다.
컴포넌트 이름은 반드시 대문자로 시작해야 한다.
예: MyComponent, Header, LoginForm
함수의 return 값에 화면에 표시할 코드(JSX) 를 넣는다.

## 재사용 (import / export)

export로 컴포넌트를 내보내면
다른 파일에서 import로 가져와서 여러 파일에서 재사용할 수 있다.
