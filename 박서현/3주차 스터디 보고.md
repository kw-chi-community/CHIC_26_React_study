# Create 생성

### 1. 의미

- 새로운 데이터를 **추가**하는 것
- 예: 할 일 추가, 댓글 작성, 게시글 생성

### 2. React 실사용 예시 코드

- 기존 배열을 복사해서 새 항목을 붙여서 `setState`

```jsx
const [todos, setTodos] = useState([]);

const addTodo = (text) => {
  const newTodo = { id: Date.now(), text, done: false };
  setTodos((prev) => [newTodo, ...prev]); // 불변성 유지
};
```

# Update 갱신

### 1. 의미

- 기존 데이터의 특정 값을 **변경**하는 것
- 예: 닉네임 변경, 게시글 수정

### 2.React 실사용 예시 코드

- `map()`으로 순회하면서 조건에 맞는 항목만 바꾼 새 배열 생성

```jsx
const toggleDone = (id) => {
  setTodos((prev) =>
    prev.map((todo) => (todo.id === id ? { ...todo, done: !todo.done } : todo)),
  );
};
```

# Delete 삭제

### 1. 의미

- 특정 데이터를 제거하는 것
- 예: 댓글 삭제, 장바구니 항목 삭제

### 2. React에서 하는 방식

- `filter()`로 삭제할 항목 제외한 새 배열 만들기

```jsx
const deleteTodo = (id) => {
  setTodos((prev) => prev.filter((todo) => todo.id !== id));
};
```
