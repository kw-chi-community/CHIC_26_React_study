# 2주차 - ch 5, 6, 7

## Props (5강)

props는 컴포넌트 외부에서 전달되는 입력값이다.
부모 컴포넌트가 자식 컴포넌트에게 데이터를 내려줄 때 사용한다.
props는 “전달받는 값”이라서 보통 컴포넌트 내부에서 직접 수정하지 않는다.

## Event (6강)

이벤트는 props를 이용한다.
보통 부모가 만든 함수를 props로 내려주고, 자식이 이벤트에서 그 함수를 실행한다.
event.preventDefault()로 기본 동작을 비활성화할 수 있다.
예: form submit 시 새로고침 방지

## State (7강)

state는 컴포넌트 내부에서 사용하는 값이다.
사용자의 입력처럼 값이 바뀌어야 하는 경우 state로 관리한다.
form을 변경(입력값 업데이트)할 때는 props로 받은 값을 그대로 바꾸는 게 아니라,
props를 state로 전환한 뒤 onChange로 state를 갱신한다.

```jsx
import { useState } from "react";

function Child({ onSubmitText, initialText }) {
  // props로 받은 초기값을 state로 전환해서 입력값을 관리
  const [text, setText] = useState(initialText);

  const handleSubmit = (e) => {
    e.preventDefault(); // form 기본 동작(새로고침) 막기
    onSubmitText(text); // 이벤트에서 props로 받은 함수 실행
  };

  return (
    <form onSubmit={handleSubmit}>
      <input
        value={text} // state 값이 input에 반영됨
        onChange={(e) => setText(e.target.value)} // 입력 변경 -> state 갱신
      />
      <button type="submit">저장</button>
    </form>
  );
}

export default function App() {
  const handleText = (value) => console.log(value); // 부모가 만든 함수

  return (
    <Child
      initialText="hello" // props: 외부에서 주는 입력값
      onSubmitText={handleText} // props: 이벤트에 쓰는 함수 전달
    />
  );
}
```
